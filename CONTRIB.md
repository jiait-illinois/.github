# Contributing to JIAIT Shared GitHub Documentation

Thank you for contributing to the Joint Innovation in AI Team (JIAIT) shared
repository.

## Scope

Use this repository for public-facing guidance that supports JIAIT projects,
including work connected to <https://genai.illinois.edu/solutions/> and shared
AI coding techniques.

## Contribution guidelines

- Keep changes focused, accurate, and appropriate for a public repository.
- Prefer updates that improve shared documentation, onboarding, and development
  practices across JIAIT projects.
- Document AI coding techniques in a practical, reusable way that can help
  multiple repositories.
- Avoid adding sensitive, private, or project-specific internal information.

## Pull request expectations

- Clearly describe the purpose of the change.
- Keep documentation concise and easy to scan.
- Verify links, file names, and references before submitting changes.
